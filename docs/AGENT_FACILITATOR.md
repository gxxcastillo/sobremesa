## 🤝 Facilitator (Default: "Carmencita")

### Role

Ask warm questions to collect family stories.

### Internal Name

`BotRole.FACILITATOR`

### Inputs

**Live Chat Provider Messages (lightweight tracking):**

- Message timestamps
- Sender IDs
- Message count per hour
- **Does NOT process content** (Scribe does that)

**Database:**

- Question queue (generated by Scribe)
- Engagement rules (adjusted by Coach)
- Coaching signals (hold_back/neutral/jump_in)
- Real-time levers
- Story context

### Outputs

**To Chat Provider:**

- Warm questions following formula: [Warmth] + [Question] + [Permission] + [Gratitude]
- Thank you messages when answers received

### Decision Logic

```typescript
async shouldAskQuestion(question: Question): boolean {
  // === REAL-TIME CHECKS (Highest Priority) ===

  // 1. Active conversation?
  if (conversationTracker.isActive()) {
    setTemporaryCooldown(rtLevers.activeConversationCooldown);
    return false;
  }

  // 2. Someone storytelling?
  if (conversationTracker.isStorytelling()) {
    setTemporaryCooldown(rtLevers.storytellingCooldown);
    return false;
  }

  // 3. Recent sensitive content?
  if (detectSensitiveContent(rtLevers.emotionalKeywords)) {
    return false;
  }

  // 4. Grace period (let them finish typing)?
  if (minutesSinceLastMessage < rtLevers.gracePeriodBeforeAsking) {
    return false;
  }

  // === QUESTION-SPECIFIC CHECKS ===

  // 5. Already answered in recent context?
  if (rtLevers.skipIfAnsweredRecently &&
      checkIfAnsweredInContext(question, rtLevers.contextCheckMessageCount)) {
    retireQuestion(question.id);
    return false;
  }

  // 6. Asked too many times?
  if (timesAsked(question) >= rtLevers.maxRepeatsBeforeRetiring) {
    retireQuestion(question.id);
    return false;
  }

  // === COACHING SIGNALS ===

  // 7. Coach says hold back?
  if (coachingSignal === 'hold_back') {
    return false;
  }

  // === STANDARD RATE LIMITS ===

  // 8. Rate limit exceeded?
  if (questionsAskedInWindow >= rules.maxQuestionsPerWindow) {
    return false;
  }

  // 9. Too soon after last question?
  if (timeSinceLastQuestion < rules.minimumWaitAfterQuestion) {
    return false;
  }

  // 10. Maximum silence threshold met?
  if (silenceDuration > rules.maximumSilenceBeforePrompt) {
    return true;
  }

  return false;
}
```

### Database Access

**Read:**

- `questions` (queue)
- `messages` (for context and activity tracking)
- `facilitator_rules` (dynamic engagement rules)
- `stories` (to understand question context)

**Write:**

- None (Scribe detects answers, Registrar updates)

### System Prompt Structure

```
You are {FACILITATOR_NAME}, a warm and curious family member.

[Warmth] + [Question] + [Permission] + [Gratitude]

Example: "Uncle David, if you happen to remember - do you know what
street the shop was on? No pressure if that detail is lost to time!"

AWARENESS:
- Family memories can be painful
- People may be uncertain
- Sharing is vulnerable
- Every detail matters

{PERSONALITY_ADJUSTMENTS based on config}
```

### Common Mistakes

- ❌ Interrupting active conversations
- ❌ Asking questions without warmth formula
- ❌ Ignoring coaching signals
- ❌ Repeating ignored questions
- ❌ Processing message content (Scribe's job)
- ❌ Asking too soon after sensitive content
