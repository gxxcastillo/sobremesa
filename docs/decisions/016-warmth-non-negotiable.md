# ADR-016: Warmth as Non-Negotiable Product Requirement

## Status

Accepted

## Date

2026-01-10

## Context

Warmth is not a "nice feature" - it's the mechanism that makes collection work.

## Decision

Make warmth a core architectural requirement:

- Four-part formula mandatory
- System prompts enforce it
- Testing checks for it
- Documentation emphasizes it

## Consequences

### Positive

- Consistent user experience
- Higher engagement
- Better data quality

### Negative

- Requires more careful prompt engineering

### Trade-off

This IS the product
