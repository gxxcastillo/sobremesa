# ADR-015: Cultural Terms Never Translated

## Status

Accepted

## Date

2026-01-10

## Context

Words like "pulpería", "gallo pinto" don't translate well.
"Corner store" loses cultural meaning.

## Decision

Maintain list of cultural terms that are:

- Never translated
- Explained in parentheses when needed
- Preserved in both language versions

## Consequences

### Positive

- Preserves cultural identity
- Educates family about heritage
- Richer, more authentic

### Negative

- Requires configuration

### Trade-off

Authenticity worth the effort
